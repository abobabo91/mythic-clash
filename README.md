# Mythic Clash

A browser-based mythological card game featuring figures from 100 cultures across the world.

## Project Phases

- [x] Phase 1 — Cultures dataset (100 cultures)
- [ ] Phase 2 — Mythological figures dataset (20 per culture = 2,000 cards)
- [ ] Phase 3 — Card game system & rules
- [ ] Phase 4 — Card stats & attributes population
- [ ] Phase 5 — Playable UI
- [ ] Phase 6 — Card artwork

## Data

- `data/cultures.json` — 100 cultures with region, period, mythology type, themes
- `data/figures/` — (coming) 20 mythological figures per culture
- `data/cards/` — (coming) full card stats and attributes
