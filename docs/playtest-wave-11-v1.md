# Playtest Wave 11 v1

Last updated: 2026-05-04

Wave 11 translated:

- `yazidi`
- `taiwanese-aboriginal`
- `georgian-nart`
- `arabian-pre-islamic`
- `thai-buddhist`

All five packs:

- export cleanly
- validate as legal `24`-card lists
- passed rollout smoke tests

## Yazidi

Identity read:

- `Sanctuary` primary
- `Oracle` secondary
- light-protection control with steady healing, selection, and clean judgment tools

Smoke record:

- `1-1` vs `Ancient Greek`
- `2-0` vs `Haitian Vodou`
- `2-0` vs `Inuit`

Both-seat spot check vs `Ancient Greek`:

- `1-3`

Main gameplay feel:

- very readable and very on-theme
- strong into slower value or tempo decks
- more seat-sensitive than the first smoke pass suggested
- still a good rollout pack, but not yet a Greek-proof benchmark deck

## Practical meaning

Wave 11 landed well overall.

`Yazidi` confirms that clean sanctuary-oracle cultures can still be competitive without needing private mechanics.

`Taiwanese Aboriginal` is an especially strong sign because it keeps a distinct cultural feel while still playing like a very legible card-game faction.

`Georgian Nart` is one of the cleanest aggressive successes in the project so far.

`Arabian Pre-Islamic` and `Thai Buddhist` both work, but they also reinforce the same ongoing signal:

- broad smoke health is not enough by itself
- the both-seat Greek gate is still the best tool for finding draw-side softness

So wave 11 is a success, but it also keeps confirming that Greek remains the main pressure benchmark for rollout quality.
