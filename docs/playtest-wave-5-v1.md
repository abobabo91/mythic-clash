# Playtest Wave 5 v1

Last updated: 2026-05-04

Wave 5 translated:

- `taino-caribbean`
- `candomble-afro-brazilian`

Both packs:

- export cleanly
- validate as legal `24`-card lists
- passed rollout smoke tests

## Taino Caribbean

Identity read:

- `Tidebound` primary
- `Sanctuary` secondary
- bounce, healing, storm clears, and sturdy ritual bodies

Smoke record:

- `1-1` vs `Ancient Greek`
- `2-0` vs `Haitian Vodou`
- `2-0` vs `Inuit`

Main gameplay feel:

- very readable
- stable midgame
- strong visible comeback tools
- does not rely on hidden burst patterns

This is a clean success.

## Candomble Afro-Brazilian

Identity read:

- `Trickster` primary
- `Sanctuary` secondary
- crossroads tempo, guarded healing bodies, ritual mana smoothing, and thunder removal

Smoke record:

- `1-1` vs `Ancient Greek`
- `1-1` vs `Haitian Vodou`
- `2-0` vs `Inuit`

Main gameplay feel:

- distinct from the other translated cultures
- understandable on first read
- more brittle into hard early pressure than Taino

I tried one retune that swapped early combat buffs for more direct damage.

That version performed worse overall, so it was reverted.

## Practical meaning

Wave 5 looks rollout-healthy at the smoke tier.

Taino is closer to "ready to trust."

Candomble is still good enough to keep, but it should get benchmark-tier follow-up later because its pressure matchups are more fragile.
