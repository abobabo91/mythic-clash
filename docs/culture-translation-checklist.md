# Culture Translation Checklist

Use this checklist each time a culture is translated into a `v1` pack.

Related standard:

- [docs/culture-rollout-rubric-v1.md](/c:/Users/abele/Desktop/github/mythic-clash/docs/culture-rollout-rubric-v1.md:1)

## Identity

- [ ] Primary family chosen
- [ ] Secondary leaning chosen
- [ ] Signature character chosen
- [ ] `3` to `5` play-pattern promises written
- [ ] `2` to `4` de-emphasized themes written

## Roster

- [ ] `20` source figures reviewed
- [ ] each figure bucketed as core / secondary / signature / salvageable / de-emphasized
- [ ] no more than a few off-plan figures remain equally loud

## Rewrite

- [ ] five-stat text removed
- [ ] unsupported subsystem language removed or rewritten
- [ ] abilities rewritten into supported `v1` primitives
- [ ] signature character stays readable and answerable

## Curve And Roles

- [ ] enough early plays exist
- [ ] enough midgame anchors exist
- [ ] at least one cleaner closer exists
- [ ] culture has interaction
- [ ] culture has at least one clear weakness

## Pack Shape

- [ ] `1` Hero added
- [ ] `20` Figures represented
- [ ] `3` culture spells added
- [ ] `1` culture relic added
- [ ] tokens added only if needed

## Deck Test

- [ ] sample `24`-card deck built
- [ ] deck validates
- [ ] deck shape does not feel fake
- [ ] support cards reinforce the family

## Runtime Test

- [ ] at least one runtime duel completed
- [ ] no obvious identity collapse into another culture
- [ ] no obvious rules confusion from signature card

## Status Label

Choose one final status:

- [ ] `assigned`
- [ ] `translated`
- [ ] `deck_validated`
- [ ] `runtime_tested`
- [ ] `needs_revision`
