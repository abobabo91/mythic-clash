# Mythic Clash Support Card Set v1

Status: locked

This document designs the first real non-figure card backbone for Mythic Clash.

The goal is not to finish all support cards forever. The goal is to create:

- a playable `Neutral Core`
- a scalable `Domain Support` layer
- a clear pattern for future culture-specific support cards

## Design Principles

Support cards should:

- make decks functional
- create archetype identity
- reduce dependence on raw figure stats
- avoid huge random pools
- stay readable

Support cards should not:

- replace the board as the main game
- create excessive hand-only burst
- invalidate the need to play Figures

## Neutral Core Set

Recommended size:

- 24 cards

Structure:

- 8 utility / tempo cards
- 8 interaction cards
- 4 stabilization cards
- 4 relics / build-around cards

All neutral core cards below are collectible, neutral, and legal in any deck.

## Why This Card Structure Works

This design gives Mythic Clash three layers of actual play texture.

Neutral Core gives:

- smooth gameplay
- baseline interaction
- tournament reliability

Domain Support gives:

- scalable flavor
- archetypes that feel mythic
- support identity without 100 custom mini-factions

Future Signature Culture cards can then give:

- a distinctive hook
- one standout build-around
- real faction personality

## Future Signature Card Pattern

Recommended signature support per culture:

- 1 iconic Relic or Spell

Examples:

- Ancient Greek: `Aegis of Athena`
- Ancient Egyptian: `Book of the Dead`
- Norse: `Gjallarhorn`
- Aztec / Mexica: `Sun Sacrifice`

These should come after the core and domain layers are stable.

## What This Means For The Rules

To support this card set cleanly, the engine should first be able to handle:

- Relics
- `Slow`, `Fast`, and `Burst` spell speeds
- targetable Heroes and Figures
- destroy / bounce / freeze / buff / draw / summon primitives
- token support
- discard / return-from-discard support
- limited discover from explicit pools

## Bottom Line

Designing the cards first shows that Mythic Clash does not mainly need more Figures.

It needs:

- a clean card grammar
- a neutral core
- domain support
- a future slot for signature culture cards

That is the structure that makes the game extensible and actually playable.
